## Agent Implementation

### System Prompt

- [ ] Implement the system prompt in `app/agent.py` using `@prompt_section` with these instructions:
  - The agent is a **Discount Strategy Advisor** for SAP S/4HANA sales orders
  - It analyzes order data (items, costs, current pricing conditions) and recommends a margin-safe discount
  - It MUST NOT recommend discounts that would bring margin below the `marginFloorPercent` threshold provided in the user message
  - It MUST return a structured JSON recommendation: `{ suggestedDiscountPercent, rationale, marginImpact, riskFlag }`
  - It MUST NOT hallucinate data — only use data returned by tool calls
  - It MUST set `$top=100` on every tool call that accepts it to prevent context overflow

### Tools

- [ ] Wire MCP tools using `get_mcp_tools()` from `mcp_tools.py` (generated by bootstrap)
- [ ] NEVER create direct HTTP clients — all S/4HANA API access goes through MCP tools

### Business Logic

The agent receives a message containing `salesOrderId`, `marginFloorPercent`, and optionally pre-fetched order data. It should:

1. **Get order data** — call the Sales Order MCP tool to fetch order header and line items (including pricing elements showing current cost and price)
2. **Get pricing conditions** — call the Pricing Condition Record MCP tool to fetch active discount condition types for the customer
3. **Analyze margin** — calculate current margin % per item: `margin = (NetAmount - CostAmount) / NetAmount * 100`. For items where CostAmount is 0, skip margin check (flag as `unknown`)
4. **Recommend discount** — based on item margins and the floor, recommend the maximum safe discount percentage. If margin headroom allows, suggest a specific % (e.g. 5%, 7%, 10%)
5. **Return structured result** — JSON with: `suggestedDiscountPercent`, `rationale` (max 3 sentences), `marginImpact` (estimated margin after discount), `riskFlag` (`low`/`medium`/`high`)

### Milestones Instrumentation

- [ ] Implement structured log statements and OpenTelemetry spans for each milestone:
  - **M1** — Order data successfully retrieved:
    - Log on achievement: `M1.achieved: sales order and pricing conditions retrieved from S/4HANA`
    - Log on miss: `M1.missed: failed to retrieve order or pricing data from S/4HANA`
    - Span name: `fetch_order_data`
  - **M2** — Margin analysis completed:
    - Log on achievement: `M2.achieved: margin analysis completed, headroom calculated`
    - Log on miss: `M2.missed: margin analysis did not complete or margin data unavailable`
    - Span name: `margin_analysis`
  - **M3** — Discount recommendation generated:
    - Log on achievement: `M3.achieved: discount recommendation generated successfully`
    - Log on miss: `M3.missed: agent failed to generate discount recommendation`
    - Span name: `generate_recommendation`
  - **M4** — Response structured and returned:
    - Log on achievement: `M4.achieved: recommendation delivered to sales rep`
    - Log on miss: `M4.missed: delivery to output channel failed`
    - Span name: `deliver_recommendation`

### Guardrails

- [ ] Add guardrail: if margin floor would be breached by any recommended discount, set `riskFlag = "high"` and cap the suggestion to the maximum safe % (which may be 0%)
- [ ] Add guardrail: agent never writes back to SAP — all tool calls are read-only
